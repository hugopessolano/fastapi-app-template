# Development Rules

These rules are mandatory for all work on this template.

## Audience and Goals
- The template is aimed at junior/trainee developers.
- Code must be easy to read, understand, and extend.
- The structure should teach good practices and support fast, safe deployments.

## Clean Code
- Prefer small, focused functions and modules.
- Keep naming explicit and consistent.
- Avoid comments unless strictly necessary; use clarity in code instead.

## TDD (Mandatory)
- Write tests first for any new behavior or change.
- Implement the code to satisfy the tests.
- Run the relevant test suite after each change to ensure it works out of the box.

## Plan Alignment
- Always work in the context of the global plan to avoid conflicts or regressions.
- Revisit the plan regularly while implementing changes.
